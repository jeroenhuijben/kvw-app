# Project Instructions

## Database Safety

- The production app remains connected to Supabase project `vdyfptpjnfigfvfvjbux`.
- Before making any change that can affect the database configuration, schema, tables, RLS policies, synchronization logic, migrations, or persisted data, explain the expected impact and risks to the user and wait for explicit approval.
- Do not change the Supabase project URL or key, run SQL, migrate data, or alter database write behavior without that approval.
- Treat database changes separately from ordinary frontend and content changes.
